# 🎬 ScreenMatch

Projeto desenvolvido em **Java** durante meus estudos de Programação Orientada a Objetos.

O projeto simula um sistema simples para cadastro e gerenciamento de **filmes e séries**, colocando em prática conceitos fundamentais da linguagem Java.

## 🚀 Tecnologias

* Java
* Programação Orientada a Objetos (POO)
* IntelliJ IDEA
* Git e GitHub

## 📚 Conceitos praticados

* Classes e objetos
* Atributos e métodos
* Encapsulamento
* Herança
* Polimorfismo
* Construtores
* Organização de pacotes

## 📂 Estrutura do projeto

```text
src/
└── br.com.curso.screenmatch/
    ├── model/
    │   ├── Filme.java
    │   └── Serie.java
    │
    └── Principal.java
```

## 🎯 Objetivo

O objetivo deste projeto é desenvolver e consolidar conhecimentos em **Java e POO**, utilizando um projeto prático como forma de aprendizado.
